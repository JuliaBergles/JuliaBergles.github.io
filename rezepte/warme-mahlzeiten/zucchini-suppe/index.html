Gespräch
Warme Mahlzeit

Zucchini-
Suppe

Cremig, wärmend, mit gekeimten Dinkelnudeln von Aho.bio.

Portionen
2–3
Zeit
25 Min
Verträglich für
Histamin · Fructose
Zutaten
  • Zucchini4 Stück
  • Gekeimte Dinkelnudeln (Aho.bio, Code SMACADO10) oder Reisnudeln1 Handvoll
  • Maisgrieß2 EL
  • Paprika Edelsüß · Salz · Curry · Kurkuma (Histaminikus, Code JULIA10734)nach Geschmack
  • Wassernach Bedarf
  • Topping: Kürbiskerne oder Pinienkerne1 Handvoll
Zubereitung
  1. Zubereitung folgt — Julia schickt sie noch nach.

Julias Tipp

Nudeln separat kochen und erst zum Servieren dazugeben — sonst weichen sie zu stark durch. Für's Topping nimm Pinienkerne, wenn Kürbiskerne bei dir nicht gehen.
