2. Geltungsbereich

Diese Datenschutzerklärung gilt für die Website juliabergles.de (gehostet via GitHub Pages), den Wear Your Healing Online-Shop sowie die mobile App „TerraLuna" (iOS/Android).

3. Datenerhebung beim Besuch der Website

3.1 Hosting (GitHub Pages)

Die Website wird über GitHub Pages bereitgestellt. GitHub erhebt automatisch Server-Logs (IP-Adresse, Browser-Typ, Uhrzeit, aufgerufene Seite). Diese Daten werden von GitHub Inc. gespeichert. Wir haben keinen Zugriff auf diese Logs.

Datenschutzerklärung von GitHub: github.com/privacy

3.2 Cookies und Tracking

Diese Website setzt keine eigenen Cookies und nutzt kein Tracking (kein Google Analytics, kein Facebook Pixel, kein Hotjar). GitHub Pages kann technisch notwendige Cookies setzen.

4. Datenerhebung bei Bestellungen (Wear Your Healing Shop)

4.1 Welche Daten werden erhoben?

Bei einer Bestellung über unser Formular werden folgende Daten erfasst:

  • Vor- und Nachname
  • E-Mail-Adresse
  • Telefonnummer (optional)
  • Lieferadresse (Straße, PLZ, Ort, Land)
  • Bestelldetails (Charm-Typ, Größe, Farbe, gewünschtes Lebensmittel)
  • Zahlungsmethode (Überweisung oder PayPal)
  • Optional: persönliche Geschichte zum Charm
  • Einwilligungen (Social Media, Datenschutz)

4.2 Formularverarbeitung (Tally)

Das Bestellformular wird über den Dienst Tally (tally.so) bereitgestellt. Tally ist DSGVO-konform und speichert Daten auf Servern in der EU (Deutschland).

Datenschutzerklärung von Tally: tally.so/help/data-privacy

4.3 Zweck der Verarbeitung

  • Abwicklung und Erfüllung deiner Bestellung
  • Kontaktaufnahme bei Rückfragen zur Bestellung
  • Zusendung der Zahlungsinformationen
  • Nach Einwilligung: anonyme Veröffentlichung deiner Geschichte auf Social Media
  • Nach Einwilligung: Video vom Designprozess auf Social Media

4.4 Zahlungsabwicklung

Vorkasse/Überweisung: Du überweist direkt auf mein Bankkonto. Deine Bank verarbeitet die Transaktion gemäß deren eigener Datenschutzbestimmungen.

PayPal: Bei Wahl von PayPal erhältst du eine Rechnung über PayPal. Es gelten die Datenschutzbestimmungen von PayPal (Europe) S.à r.l. et Cie, S.C.A.

4.5 Speicherdauer Bestelldaten

Bestelldaten werden für 10 Jahre aufbewahrt (handels- und steuerrechtliche Aufbewahrungspflicht gem. §257 HGB, §147 AO). Danach werden sie gelöscht.

5. Datenerhebung in der TerraLuna App

5.1 Lokal gespeicherte Daten (nur auf dem Gerät)

Folgende Daten werden ausschließlich auf dem Smartphone gespeichert:

  • Profildaten: Name, Ernährungspräferenzen, ausgewählte Filter, Gewicht, Größe, Aktivitätslevel, persönliche Ziele
  • Zyklusdaten: Zykluslänge, Periodenlänge, letzter Periodenstart, tägliche Stimmungs-/Energie-/Symptomeinträge
  • Tagebucheinträge: Tägliche Notizen, Stimmung, Verträglichkeit, Bewegung, Fotos, eigene Felder
  • Einkaufslisten: Erstellte Listen und abgehakte Produkte
  • Scan-Verlauf: Barcode-Scans und Analyseergebnisse
  • Favoriten: Gespeicherte Rezepte
  • Lernfortschritt: Abgeschlossene Lernkarten

Speichermethode: AsyncStorage-Technologie. Daten werden beim Deinstallieren der App gelöscht.

5.2 Besondere Datenkategorien (Art. 9 DSGVO)

Die App verarbeitet Gesundheitsdaten (Zyklusdaten, Symptome, Verträglichkeiten, Ernährung). Die Verarbeitung erfolgt auf Grundlage der ausdrücklichen Einwilligung der Nutzerin während des App-Onboardings.

5.3 Datenübermittlung an Dritte (App)

  • Barcode-Scanner: EAN-Nummern werden an Open Food Facts (openfoodfacts.org) zur Produktabfrage übermittelt
  • Verträglichkeits-Scanner (Premium): Essensfotos werden an die Anthropic API zur Analyse übermittelt; Fotos werden nicht gespeichert
  • Reise-Übersetzer: Texte werden an MyMemory (mymemory.translated.net) zur Live-Übersetzung übermittelt
  • YouTube-Videos: Workouts leiten zu YouTube weiter; es gelten die Datenschutzbestimmungen von Google/YouTube
  • Partner-Links: HistaFood, Histaminikus, Aho.bio, Nigela leiten auf die jeweiligen Websites weiter

5.4 Kamerazugriff

Erforderlich für: Barcode-Scannen, Essensfotografie (Verträglichkeits-Scanner), Tagebuch-Fotos. Zugriff nur mit ausdrücklicher Erlaubnis.
